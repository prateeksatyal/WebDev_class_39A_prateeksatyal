This folder contains 10 beginner-friendly JavaScript solutions based on the supplied practice PDF.

## Files
1. `01_electricity_bill.js`
2. `02_student_result.js`
3. `03_shopping_discount.js`
4. `04_movie_ticket.js`

7. `07_atm_withdrawal.js`
8. `08_restaurant_order.js`
9. `09_mobile_recharge.js`
10. `10_smart_calculator.js`

## How to run
1. Open this folder in VS Code.
2. Open a terminal in the folder.
3. Run an individual file with Node.js, for example:

```bash
node 01_electricity_bill.js
```

Each file is independent. The solutions use arrow functions, callbacks, `return`, and `console.log()`.
