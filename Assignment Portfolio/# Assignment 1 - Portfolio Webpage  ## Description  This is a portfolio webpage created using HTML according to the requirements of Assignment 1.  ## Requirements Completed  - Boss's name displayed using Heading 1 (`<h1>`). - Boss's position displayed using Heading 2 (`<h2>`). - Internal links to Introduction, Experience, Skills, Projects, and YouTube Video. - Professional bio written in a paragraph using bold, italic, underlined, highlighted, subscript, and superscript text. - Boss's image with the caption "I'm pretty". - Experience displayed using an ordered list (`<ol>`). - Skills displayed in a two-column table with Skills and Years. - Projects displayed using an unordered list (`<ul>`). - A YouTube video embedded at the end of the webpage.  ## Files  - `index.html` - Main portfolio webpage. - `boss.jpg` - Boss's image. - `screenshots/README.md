# Assignment 1 - Portfolio Webpage

## Description

This is a portfolio webpage created using HTML according to the requirements of Assignment 1.

## Requirements Completed

- Boss's name displayed using Heading 1 (`<h1>`).
- Boss's position displayed using Heading 2 (`<h2>`).
- Internal links to Introduction, Experience, Skills, Projects, and YouTube Video.
- Professional bio written in a paragraph using bold, italic, underlined, highlighted, subscript, and superscript text.
- Boss's image with the caption "I'm pretty".
- Experience displayed using an ordered list (`<ol>`).
- Skills displayed in a two-column table with Skills and Years.
- Projects displayed using an unordered list (`<ul>`).
- A YouTube video embedded at the end of the webpage.

## Files

- `index.html` - Main portfolio webpage.
- `boss.jpg` - Boss's image.
- `screenshots/` - Screenshots of the completed webpage.

## Technology Used

- HTML5
