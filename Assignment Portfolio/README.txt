# Assignment 1 – Portfolio Webpage

## Description

This project is a portfolio webpage created using **HTML** according to the requirements of Assignment 1.

## Requirements Completed

- Boss's name displayed using a **Heading 1 (`<h1>`)**.
- Boss's position displayed using a **Heading 2 (`<h2>`)**.
- Internal links to the **Introduction, Experience, Skills, Projects, and YouTube Video** sections.
- Professional bio in a paragraph using **bold, italic, underlined, highlighted, subscript, and superscript** text.
- Boss's image with the caption **"I'm pretty"**.
- Experience displayed using an **ordered list (`<ol>`)**.
- Skills displayed in a **two-column table** containing **Skills** and **Years**.
- Projects displayed using an **unordered list (`<ul>`)**.
- A **YouTube video** embedded at the end of the webpage.

## Files

- `index.html` – Main portfolio webpage.
- `boss.jpg` – Boss's image.
- `screenshots/` – Screenshots of the completed webpage.

## Technology Used

- HTML5
