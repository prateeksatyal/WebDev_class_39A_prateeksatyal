# Portfolio Webpage

## Assignment 1 - HTML Portfolio

### Description

This is a portfolio webpage created using HTML according to the requirements of Assignment 1.

### Requirements Completed

* Boss's name displayed using Heading 1.
* Boss's position displayed using Heading 2.
* Internal links to Introduction, Experience, Skills, Projects, and YouTube Video.
* Professional biography using bold, italic, underlined, highlighted, subscript, and superscript text.
* Boss's image with a caption.
* Experience displayed using an ordered list.
* Skills displayed using a two-column table.
* Projects displayed using an unordered list.
* YouTube video embedded at the end of the webpage.

## Assignment 2 - Styling the Portfolio Using CSS

### Description

The portfolio webpage from Assignment 1 has been styled using CSS according to the requirements of Assignment 2.

### Requirements Completed

* Name displayed in the center of the page.
* Position displayed below the name.
* Navigation links displayed horizontally without text decoration.
* Header styled with a different color from the body.
* Introduction title displayed on the left and in bold.
* Introduction paragraph justified.
* Image centered with a caption.
* Rounded edges added to the webpage elements.
* Experience items displayed with alternating light and bold font weights.
* Skills table styled using CSS.
* Project section styled using CSS.
* YouTube video centered and properly sized.
* Contact form added with name, email, phone number, gender, and role fields.
* Page made responsive for different screen sizes.
