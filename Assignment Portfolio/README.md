# Assignment 1 - Portfolio Webpage

## Description

This is a portfolio webpage created using HTML according to the requirements of Assignment 1.

## Requirements Completed

- Boss's name displayed using Heading 1.
- Boss's position displayed using Heading 2.
- Internal links to Introduction, Experience, Skills, Projects, and YouTube Video.
- Professional biography using bold, italic, underlined, highlighted, subscript, and superscript text.
- Boss's image with the caption "I'm pretty".
- Experience displayed using an ordered list.
- Skills displayed in a two-column table.
- Projects displayed using an unordered list.
- YouTube video embedded at the end of the webpage.

## Files

- `index.html` - Main portfolio webpage.
- `boss.jpg` - Boss's image.
- `screenshots/` - Screenshots of the completed webpage.

## Technology Used

- HTML5
